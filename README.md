# practica-mvc-universidad

Este royecto corresponde a una practica academica desarrollada en java utilizando el patron de arquitectura MVC (Modelo-Vista-Controlador) y conexion con postgreSQL.

## objetivo

Implementar un sistema basico de gestion universitaria que permita realizar operaciones CRUD (Crear,Leer,Actualizar y Eliminar)sobre diferentes entidades academicas.

## entidades principales

-Estudiante
-Docente
-Materia
-Grupo
-Inscripcion de Curso
